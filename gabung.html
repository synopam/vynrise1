Cara Bergabung

Gunakan IP dan Port di bawah ini untuk menghubungkan game ke server.

💻

Java Edition (PC / Laptop)

SERVER ADDRESS (IP) nyxrise.sytes.net:22093
  1. Buka Minecraft Java Edition (Versi 1.18.2+).
  2. Pilih menu Multiplayer > Add Server.
  3. Masukkan Server Address: nyxrise.sytes.net:22093.
  4. Klik Done lalu pilih server dan klik Join Server.
📱

Bedrock Edition (HP / PE)

SERVER ADDRESS (IP) nyxrise.sytes.net
PORT 22093
  1. Buka Minecraft Bedrock / MCPE di HP Android/iOS.
  2. Masuk ke menu Play > tab Servers.
  3. Scroll ke paling bawah dan klik Add Server.
  4. Isi Alamat IP: nyxrise.sytes.net dan Port: 22093.
  5. Klik Save lalu klik Join Server.
